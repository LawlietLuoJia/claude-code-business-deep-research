# Competitive Lens

Use this lens for peer comparison and competitive dynamics.

## Sequence

1. Define the market boundary and the decision the comparison supports.
2. Select the peer set: direct, adjacent, incumbent, or emerging.
3. Identify the industry-defining metrics and qualitative dimensions before comparing.
4. Compare positioning, strengths, weaknesses, trajectory, and moat sources.
5. Explain what the comparison changes for the user's decision.

## Evidence Rules

- Keep metric definitions comparable.
- Use the same time period where practical and flag exceptions.
- Distinguish public facts, estimates, and vendor positioning.
- Use community and customer voice for adoption frictions and sentiment, not as the sole basis for market facts.

## Useful Outputs

- Peer map
- Comparison matrix with citations or evidence IDs
- Moat and vulnerability assessment
- Signposts that would change the competitive judgment
