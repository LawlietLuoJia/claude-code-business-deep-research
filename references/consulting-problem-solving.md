# Consulting Problem Solving Lens

Use this lens when the user is asking for a decision, prioritization, strategy, or option choice.

## Pattern

1. Define the decision and what would make an answer usable.
2. Break the question into a small issue tree that is mutually distinct enough to drive research.
3. Form hypotheses as search accelerators, not as conclusions.
4. Test each material hypothesis against supporting and disconfirming evidence.
5. Build a recommendation chain: evidence -> implication -> option -> recommendation -> risk.

## Guardrails

- Keep issue trees smaller than the research problem needs; deep research is not improved by taxonomy volume.
- Retire hypotheses that evidence defeats.
- Do not turn this lens into a slide or dummy-page workflow unless the user asks for a deck.
