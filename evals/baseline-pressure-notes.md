# Baseline Pressure Notes

## Status

This is a dry-run baseline recorded before the first `business-deep-research` draft. The current task did not authorize delegated baseline agents, so the notes come from inspecting the existing comparison skills and their stated workflows.

## Existing Skill Pressure Points

| Comparison path | Baseline strength | Baseline risk to test |
|---|---|---|
| No skill | Fast ad hoc answer | May skip scope gates, evidence artifacts, and search accounting |
| Local `deep-research` | Strong evidence persistence and citation rigor | May default to academic report structure or heavier claim protocol than normal commercial work needs |
| `hv-analysis` | Strong history/current-position narrative | Can overfit company and product topics and make other commercial questions follow a timeline lens |
| `competitive-analysis` | Strong peer and moat comparison | Deck-first framing can displace report evidence package and broader research design |
| `market-research-reports` | Broad market report coverage | Large report and framework stack can add unnecessary volume |
| `mckinsey-consultant` | Problem framing, issue tree, hypothesis discipline | PPT and dummy-page workflow is not a research default |

## Draft Requirements Created By Baseline

1. The new skill must state its two gates clearly enough that an agent does not draft a polished report before the research direction is confirmed.
2. Search routing must separate primary evidence from leads and AI-generated reconnaissance.
3. The skill must name the evidence artifacts every full run should produce.
4. Framework selection must happen after evidence review and select one primary lens.
5. The default path must exclude TinyFish Agent and Browser.
